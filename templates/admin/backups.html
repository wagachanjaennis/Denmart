DATA PROTECTION

Backups and recovery

Create a verified copy of the complete application database, or restore a saved copy. The SQLite route streams every table in batches and verifies the resulting file before it is offered for download.

Download a backup

Both downloads contain every application table and row currently in the database, including settings, staff, marts, orders, sales, payments, stock, audit records and product data.
Download JSONPortable full-system data snapshotDownload SQLiteVerified database snapshot with row-count checks
Large backup noteSQLite export is streamed in bounded batches so Python does not load the whole database into memory. The practical maximum is the disk space and request/download limits of your hosting provider.

Restore a snapshot

A restore replaces the current database with the selected saved state. Use a backup produced by this application where possible.
PROTECTED ACTION

What is included

The snapshot covers every application table registered by the current schema. Uploaded product images stored as database data are included. Remote image URLs remain URLs and are not silently replaced with copies.

Fresh-install recoveryOn a fresh deployment, initialise the database, open Backups, upload the saved JSON or SQLite file, confirm RESTORE, then sign in again with the restored credentials.
